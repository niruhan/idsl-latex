# Western thesis scaffold

Edit `config.typ`, replace the preliminary text in `front-matter.typ`, and write
chapters under `chapters/`. Add includes in `main.typ` as needed.

This is a starting scaffold with Letter pages, a 1.5-inch left margin, 1-inch
other margins, Roman preliminary page numbers, Arabic chapter page numbers,
references, and an appendix. It uses only built-in Typst features.

Check the current [Western SGPS formatting requirements](https://www.grad.uwo.ca/academics/thesis/formatting.html)
and your program's requirements before submission. Adjust spacing, front matter,
declarations, and other details for your degree. This is not an approved or
submission-certified university template. All names and text are placeholders.
