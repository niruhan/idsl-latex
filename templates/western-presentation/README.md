# Western presentation starter

Edit the title, subtitle, presenter, and department in `main.typ`. Add slides in `sections/`, and customize colors and helper boxes in `shared.typ`.

This starter preserves the supplied Western presentation's 16:9 Touying university layout, 20 pt Libertinus Serif text, purple palette, title logo, section headers, and note/strength/weakness/discussion boxes. Personal metadata and presentation content have been replaced with examples. The app's interface theme does not change these slide colors.

This starter imports `@preview/touying:0.5.3`. IDSL Editor includes that package once in its shared compiler library, so live preview and PDF export work offline without copying library files into your project. Outside IDSL Editor, a standard Typst installation downloads the pinned package from Typst Universe on first use. Touying is MIT licensed; its original license is retained in the app's `typst-packages/preview/touying/0.5.3/LICENSE`. Use the same package import when adding section files, as in the supplied examples.
