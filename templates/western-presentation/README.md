# Western presentation starter

Edit the title, subtitle, presenter, and department in `main.typ`. Add slides in `sections/`, and customize colors and helper boxes in `shared.typ`.

This starter preserves the supplied Western presentation's 16:9 Touying university layout, 20 pt Libertinus Serif text, purple palette, title logo, section headers, and note/strength/weakness/discussion boxes. Personal metadata and presentation content have been replaced with examples. The app's interface theme does not change these slide colors.

Touying 0.5.3 is included under `vendor/touying/` with its MIT license, so this starter needs no Typst Universe downloads. It has no external package dependencies. See `vendor/touying/LICENSE` for attribution. Use local imports when adding section files, as in the supplied examples.
