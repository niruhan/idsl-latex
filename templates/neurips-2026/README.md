# NeurIPS 2026 paper starter

Start with `main.tex`. The default uses the official anonymous Main Track style. Replace all placeholder text and complete every TODO in `checklist.tex` for your own paper. Select `[preprint]` for a public draft, or `[main,final]` for an accepted camera-ready paper. Consult the conference instructions before submitting; this starter does not check submission compliance.

`neurips_2026.sty` and `checklist.tex` are unmodified files from the official NeurIPS 2026 author kit, provided by the NeurIPS 2026 Program Chairs. The remaining manuscript is an app-authored example. Original author attribution in the style file is retained.

- Official author kit: https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip
- Conference instructions: https://neurips.cc/Conferences/2026/CallForPapers
- Official template listing and CC BY 4.0 license: https://www.overleaf.com/latex/templates/formatting-instructions-for-neurips-2026/bjdwqfdkyftc
- License: https://creativecommons.org/licenses/by/4.0/

The app bundles the style and checklist; LaTeX packages are supplied by your compiler. On a Mac, Tectonic may download packages on the first build. On an offline Linux installation, the configured TeX bundle must contain the required packages.
